# Print collected GraphQL rows

Print collected GraphQL rows

## Usage

``` r
# S3 method for class 'fabric_graphql_rows'
print(x, ...)
```

## Arguments

- x:

  A `fabric_graphql_rows` tibble returned by
  [`fabric_graphql_collect()`](https://kennispunttwente.github.io/fabricQueryR/reference/fabric_graphql_collect.md)

- ...:

  Additional arguments passed to the tibble print method

## Value

`x`, invisibly
