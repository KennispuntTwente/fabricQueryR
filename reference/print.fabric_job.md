# Print a submitted Fabric job

Print a submitted Fabric job

## Usage

``` r
# S3 method for class 'fabric_job'
print(x, ...)
```

## Arguments

- x:

  A `fabric_job` handle returned by
  [`fabric_job_run()`](https://kennispunttwente.github.io/fabricQueryR/reference/fabric_job_run.md)

- ...:

  Reserved for the print method

## Value

`x`, invisibly
